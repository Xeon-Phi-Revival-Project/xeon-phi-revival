# Ubuntu / K1OM Port Research

This directory contains experimental work toward rebuilding a broader modern
source/userland ecosystem for K1OM. It documents package, dependency, toolchain,
and compatibility investigations; it is **not** evidence that Ubuntu 24.04
packages can currently be installed normally on XPR-OS.

Use these notes as input to future SDK/toolchain and source-package work. The
longer-term concept of rebuilding source packages for K1OM is still future work.

For current runnable XPR-OS guidance, use [Getting Started](../getting-started/README.md).
For compiler/runtime work, see [Toolchain Research](../toolchain/README.md).
