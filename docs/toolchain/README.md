# K1OM Toolchain Research

This directory tracks compiler, runtime, package, sysroot, and SDK evidence for
building Knights Corner / K1OM software.

Useful entry points include:

- [K1OM package requirements](k1om-package-requirements.md)
- [SDK package report](mpss-sdk-k1om-package-report.md)
- [Runtime dependency analysis](runtime-dependency-analysis.md)
- [Runtime source package map](runtime-source-package-map.md)
- [Open toolchain feasibility](open-toolchain-feasibility.md)
- [Open toolchain roadmap](open-toolchain-roadmap.md)

The practical roadmap is to establish a clean, reproducible K1OM compiler/sysroot
experience before attempting a new modern GCC/LLVM backend. Research documents
here do not by themselves constitute a supported compiler release.
