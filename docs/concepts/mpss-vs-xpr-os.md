# MPSS And XPR-OS

MPSS is the historical Intel host software used by the tested KNC path. XPR-OS
uses the MPSS host driver and management mechanism as an external prerequisite,
but supplies the project-built kernel, modules, bootstrap, and final userspace
artifacts in RC6. Intel MPSS packages, firmware, stock uOS contents, and
extracted sysroots are not included in the release.
