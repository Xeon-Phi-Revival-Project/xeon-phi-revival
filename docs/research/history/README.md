# Historical Project Records

This directory contains **superseded project-state and planning documents** that
remain useful for provenance, chronology, and understanding how XPR developed.
They are intentionally separated from current user and developer instructions.

Do not treat commands or status statements in these files as current guidance.
For the present project state, use [Project Status](../../status.md), and for
installation use [Getting Started](../../getting-started/README.md).

## Preserved Records

- [Project pause checkpoint](project-paused-2026.md) — the historical period when work was blocked around the earlier 71S1P path.
- [Pre-publication audit, 2026-07-27](publication-audit-20260727.md) — a dated publication-readiness snapshot.
- [Initial development plan](initial-development-plan.md) — the large early living plan/notebook, preserved rather than left at repository root.
- [Wiki plan](wiki-plan.md) — an early publishing-surface plan.
- [Pages plan](pages-plan.md) — an early GitHub Pages planning note.

These files are retained as history; their presence does not imply that their
planned work, blockers, or status language remains current.
