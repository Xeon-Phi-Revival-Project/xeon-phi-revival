# Artifacts

This directory contains **generated inspection, audit, and experiment outputs**
retained as project evidence. It is not a user download area and it is not the
canonical documentation front door.

Some files may look redundant because different audit/reporting steps can emit
the same underlying data in different groupings or paths. Do not delete or
“deduplicate” evidence solely by filename or matching hash without first checking
which manifest/report expects it.

For current user guidance, start at the repository [README](../README.md). For
research navigation, use [docs/research](../docs/research/README.md), and for the
records that describe experiments/releases, see [manifests](../manifests/README.md).
