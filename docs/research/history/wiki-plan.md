# GitHub Wiki Plan

Canonical documentation belongs in this repository's `docs/` directory so it
is reviewed, versioned, and shipped with source. A future GitHub Wiki should be
supplementary, not a competing installation manual.

Recommended Wiki pages: a home page linking to [Getting Started](getting-started/README.md),
community hardware reports, common questions, terminology pointers, and
community tips. Each should link back to the canonical document rather than
copying it.
