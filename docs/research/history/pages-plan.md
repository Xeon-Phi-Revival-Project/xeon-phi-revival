# GitHub Pages Documentation Plan

Do not deploy a Pages site automatically. When the project is ready, use a
lightweight static generator such as MkDocs with repository Markdown as the
single canonical source. A future site should expose Getting Started,
Troubleshooting, Concepts, Hardware, Development, Architecture, Glossary, and
FAQ with search and mobile-friendly navigation.

Suggested metadata:

```text
site_name: XPR-OS - Intel Xeon Phi Knights Corner Revival
site_description: Open-source K1OM boot and Linux userspace environment for Intel Xeon Phi Knights Corner coprocessors.
```

No analytics or tracking is needed.
