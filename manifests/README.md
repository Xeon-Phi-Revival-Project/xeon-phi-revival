# Manifests

Manifests are the structured evidence layer for XPR experiments, hardware
observations, builds, and releases. They are kept separate from beginner
documentation so captured evidence can remain detailed without turning the user
path into a lab notebook.

Use manifests when you need to answer questions such as:

- what hardware/host configuration produced a result;
- which inputs, hashes, and build products were involved;
- whether a claim came from a real-card experiment or a host-only fixture; or
- which evidence supported a release decision.

Do not rewrite historical manifests to match current terminology; add new/current
evidence instead. Generated supporting output is retained under
[artifacts](../artifacts/README.md).

For readable research navigation, see [docs/research](../docs/research/README.md).
